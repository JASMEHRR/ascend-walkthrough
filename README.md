# Ascend walkthrough

A walkthrough video of [Ascend](https://github.com/JASMEHRR/ASCEND), my life dashboard, made entirely in code with [Remotion](https://www.remotion.dev) (React).

- The finished video is in `out/ascend-walkthrough.mp4`.
- The scenes are React components in `src/`.

## Render it again
```
npm install
npx remotion studio    # preview
npx remotion render    # render the video
```
